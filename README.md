## Research

**[Structured Multi-Step Reasoning](https://github.com/Thundercok/structured-multi-step-reasoning)**
Fine-tuning Qwen3-8B (MLX, Apple Silicon) to write its reasoning as checkable steps, then editing those steps to test whether the final answer actually depends on them. Pre-registered analyses, raw outputs in the repo.

**[VRPTW Neural Hybrid Optimizer](https://github.com/Thundercok/vrptw-neural-hybrid-optimizer)**
Vehicle routing with time windows: ALNS with a Dueling Double DQN choosing operators, GNN edge guidance and set-partitioning recombination, measured on Solomon and Homberger instances.

**[Bounded Reasoning Harness](https://github.com/Thundercok/bounded-reasoning-harness)**
Small open-weight coding agents (Gemma 4 E4B) under a fixed thinking budget, with a deterministic check of each patch before it is submitted.

## On-device systems

**[Deterministic Local Assistant](https://github.com/Thundercok/deterministic-local-assistant)**

**[Verified Document Intake](https://github.com/Thundercok/verified-document-intake)**
